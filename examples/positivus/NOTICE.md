## Modifications from the original

Per CC BY 4.0 §3(a)(1)(B), changes from the original design are noted:

- The design was implemented as production HTML/CSS (the original is a static Figma file)
- Body copy for Process cards 02–06 is invented; the original Figma file only contains text for card 01
- Mobile breakpoints (1200 / 1024 / 768 px) were derived from the desktop spec — the original Figma file contains no mobile frames
- Raster assets are exported at 1x (the Figma MCP screenshot tool caps at 1x)
